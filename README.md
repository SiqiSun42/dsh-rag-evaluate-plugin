# dsh-rag-evaluate

运行在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 上的 RAG 系统评测插件。

给它一个工作区，它会发现里面的向量库与查询入口，构建评测集，跑出指标，并指出问题出在哪一层、下一步该改什么。

## 现状

**早期开发中，八个步骤里只有第①步已实现。**

| 步骤 | 内容 | 状态 |
|---|---|---|
| ① | 清点：确认向量库与查询入口是否存在，整理候选链路 | 已实现 |
| ② | 探测画像：向量库的规模、维度、内容主题与质量缺陷 | 未实现 |
| ③ | 确认形态与方向：评测集要模拟的查询样式与覆盖范围 | 未实现 |
| ④ | 冻结规格：固化为可版本化的规格 | 未实现 |
| ⑤ | 生成评测集 | 未实现 |
| ⑥ | 执行与判定：检索、相关性判定、指标 | 未实现 |
| ⑦ | 效度校验：确认本次运行结果可信 | 未实现 |
| ⑧ | 归因分析：定位问题层级，给出建议 | 未实现 |

## 工作方式

插件不自带命令行入口。它把一个 skill 交给 Agent，由 Agent 按步骤执行，产物落盘到被测工作区的 `evaluation/<运行标识>/` 下。

进度由产物决定而非记忆：检查运行目录里已有哪些文件，就知道走到了哪一步。因此换一个会话也能接着上次继续。

插件不修改被测项目的任何已有文件，也不改写查询——它只评测系统原本的行为。

## 安装

需要先装好 DSH。

```sh
dsh plugin --profile web add <本仓库路径>
```

首次运行会自动创建 Python 环境并安装依赖。

装完重启 DSH，然后**新开一个会话**（会话启动时才会读取 skill 目录）。

## 使用

在装有该插件的工作区里，直接对 Agent 说：

```
帮我评测一下这个 RAG 系统
```

也可以显式调用：

```
/rag-evaluate
```

第①步完成后会给出候选链路清单和结构性问题；确认无误再进行下一步。

## 要求

- DSH
- Python 3（用于后续步骤；第①步本身不依赖它）
- 被测系统需要包含一个向量库和一个查询入口
